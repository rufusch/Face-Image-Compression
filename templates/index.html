Decompose each image channel
A = UΣVᵀ splits the pixel matrix into singular vectors and singular values.
Reconstruct at rank r
Aᵣ = Uᵣ diag(sᵣ) Vᵣᵀ keeps the first r components. The squared error before rounding is the sum of the discarded squared singular values.
Recover the archive reference
A = round_and_clip(Aᵣ) + E, where E is the signed pixel difference stored in a new archive.
